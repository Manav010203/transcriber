# transcriber
This repo contains a openai model whisper which i used to get transcription of a mp4/mp3 file. In the Full Transcription you will get the whole transcription and In the Subtitles block you get the transcription timed properly with the file in order to get the subtitles for the file.

The HuggingFace Link for the project is:
https://huggingface.co/spaces/thesurveycorps/transcriber

The code in the repo you can see how it is built.
